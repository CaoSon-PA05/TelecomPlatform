## CÁCH KIỂM TRA TỪNG LỚP

### Lớp 1 — Splash Screen
1. Mở `index-Son0Cao0PC.html` trong trình duyệt (lần đầu)
2. Quan sát màn hình Splash Screen hiện trong ~1.8 giây
3. Quan sát hiệu ứng loading bar chạy, logo pulse
4. Xác nhận tự động chuyển vào giao diện chính sau khi fade

### Lớp 2 — Footer Watermark
1. Mở ứng dụng bất kỳ màn hình nào
2. Nhìn xuống góc dưới cùng của trang
3. Xác nhận dòng chữ nhỏ: `TelecomPlatform™ · Gravity Intelligence Lab · Designed by Cao_Son_Hinh su_CNC`
4. Kiểm tra footer không block các nút/bảng phía dưới

### Lớp 3 — About Dialog
1. Nhìn vào cuối sidebar (dưới cùng)
2. Click `ⓘ GIỚI THIỆU HỆ THỐNG`
3. Xác nhận dialog hiện với thông tin tác giả đầy đủ
4. Test đóng bằng: nút ✕, click backdrop, phím Escape

### Lớp 4 — Export Signature
1. Vào CDR Analyzer → nạp file XLSX → click xuất Excel
2. Mở file XLSX xuất ra
3. Kiểm tra có sheet tên `Signature` ở cuối
4. Xác nhận nội dung sheet có thông tin tác giả và timestamp xuất file
5. Lặp tương tự với: Batch Export, Summary Export

### Lớp 5 — Metadata
1. Mở `package.json` → kiểm tra `author`, `organization`
2. Mở `AUTHOR.md` → kiểm tra nội dung
3. (Dev tools) Console: `document.title` → `Sentinel Core | Precision Data & Analytics System`

## GHI CHÚ KỸ THUẬT

- Splash Screen kiểm tra `sessionStorage` sẽ **không** bỏ qua splash — splash luôn hiển thị khi tải trang, độc lập với login
- Footer có `z-index: 900`, thấp hơn các dialog/modal (`z-index: 9999+`) nên không bị che khuất bởi footer
- Signature trong export dùng `XLSX.utils.aoa_to_sheet` (Array of Arrays) — tương thích hoàn toàn với SheetJS version đang dùng
- Tất cả CSS classes đều được namespace bằng prefix `gravity-` để tránh xung đột với CSS hiện có
